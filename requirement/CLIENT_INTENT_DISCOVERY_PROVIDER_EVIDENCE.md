## §4 Google / Google Search

Facts (S1–S4):

- The Custom Search JSON API returns JSON per OpenSearch 1.1; authentication by API key; 100 free queries/day;
  USD 5 per 1,000 additional queries up to 10,000/day (S1).
- **"The Custom Search JSON API is closed to new customers"**; existing customers have until 2027-01-01 to
  transition; S1 points to Vertex AI Search for domain-specific searches (S1). Vertex AI Search was not consulted.
- Result fields: `title`, `htmlTitle`, `link`, `displayLink`, `snippet`, `htmlSnippet`, `cacheId`, `formattedUrl`,
  `htmlFormattedUrl`, `pagemap`, `mime`, `fileFormat`, `image`, `labels`; **no per-result date field** (S2).
- Google APIs Terms: no scraping, building databases or permanent copies of API content, or caching beyond the cache
  header (§5.e); no circumventing documented limits (§2.d); no masking identity (§2.c); credentials confidential
  (§4.b); required attributions (§6.b); delete cached content on termination (§8.b); User Data Policy (§3.d) (S3).
- Google Terms of Service prohibit automated access contrary to machine-readable instructions such as robots.txt
  ("Don't abuse our services") (S4).

Not established: any Google product that supplies organization-expressed service-need statements; whether the
Custom Search engine scope covers the general web; Vertex AI Search capabilities.

## §5 Google Ads

Kept separate from §4. GA-Q0 to GA-Q15 (INTENT-INTAKE-GOOGLE-ADS-REQ-001) are **not resolved** by this record; facts
below are recorded only as evidence relevant to them.

- The Google Ads API is "the programmatic interface to Google Ads, used for managing large or complex Google Ads
  accounts and campaigns"; requires a developer token and OAuth; manager account for multi-account management (S5).
- Lead Form Webhook: after a user clicks an ad and submits the lead form, an HTTP POST is sent to the URL the
  advertiser configured (S7).
- Payload fields include `lead_id`, `user_column_data` (`column_id`, `string_value`, `column_name`), `api_version`,
  `form_id`, `campaign_id`, `google_key`, `is_test`, `gcl_id`, `adgroup_id`, `creative_id`, `lead_submit_time`
  (ISO-8601), `lead_source` (`LEAD_FORM` or `CONVERSATIONAL_AGENT`), `asset_group_id`, `lead_stage` (S8).
- Available column IDs include `FULL_NAME`, `EMAIL`, `PHONE_NUMBER`, `COMPANY_NAME`, `JOB_TITLE`, `WORK_EMAIL`,
  `WORK_PHONE`, address fields and others (S8).
- Validation: compare `google_key` in the payload with the value configured in Google Ads (S8). No signature
  algorithm is documented; Ed25519 is not established.
- Google Ads API Terms: access only by documented means; no misrepresenting identity (§1.4); privacy-law compliance
  and personal-information use consistent with consent (§7(A)); GDPR contracts (§7(B)) (S6).

Relevant-to (not resolving): GA-Q1 (S5, S7), GA-Q3 (S8), GA-Q5 (S7 push), GA-Q7 (S8: no signature documented),
GA-Q8 (S5, S8), GA-Q11 (S8 `lead_submit_time`), GA-Q15 (S6 §7, S8 fields).

Analyst observation (repository fact, not a decision): several S8 fields (`EMAIL`, `PHONE_NUMBER`, `FULL_NAME`,

Not established: quotas, pricing, retention / deletion periods specific to lead data; any Google Ads source of intent
from businesses other than the advertiser's own respondents.

- User Agreement §8.2: no scraping or copying the Services by software, scripts, crawlers or plug-ins (8.2.2); no
  bots or unauthorized automated methods (8.2.13); no copying or distributing information obtained from the Services
  without the content owner's consent (8.2.4); no use of another's account, sharing log-ins or copying cookies
  (8.2.1); no overriding security features or bypassing access controls or use limits (8.2.3) (S11).
- API Terms: no storing Content unless expressly permitted (§4.1); delete on member request / termination (§4.4,
  §4.5); minimal data (§3.1(7)); no distribution to third parties (§3.1(8)); no content obtained by scraping
  (§3.1(24)); no combining Content (§3.1(25)); credentials not shared beyond employees / contractors (§2.2); brand

- Restricted uses: member data (profile portions, identifiers, posts, comments, reactions) **must not be used for
